# MTA - German Los Angles Reallife - lareallife
MTA Server Skript lareallife von Leyynen

Dies ist ein Multi Theft Auto (MTA) Server Skript, das ursprünglich von Leyynen vor mehr als 10 Jahren auf dem Forum mta-sa.org veröffentlicht wurde.
Dieses Repository wurde erstellt, um das Skript der Allgemeinheit wieder zugänglich zu machen, da alle Download Links nicht mehr funktionieren.

## Ursprünglicher Autor

**Name des Autors**: Unbekannt 
**Forum Benutzername**: Leyynen 
**Originalveröffentlichung**: 26.12.2013

## Projektbeschreibung

Das German Los Angeles Reallife Skript bietet dem Spieler das erlebnis sich frei in einer von Los Angeles insperierten Welt zu bewegen.
Die Repository dient auch dazu Bugs zu fixen und es auf der aktuellen MTA-Version spielbar zu machen.

## Installation

[Anleitung zur Installation des Skripts. Wie kann man das Skript auf einem MTA-Server einrichten?]

1. Schritt 1 MySQL Server installieren z.B. (mariaDB) und einrichten
2. Schritt 2 MTA-Server für Windows oder Linux installieren und einrichten
3. Schritt 3 Gamemmode bzw. notwendige Ressourcen ins Serververzeichnis laden
